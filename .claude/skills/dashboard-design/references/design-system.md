# Дизайн-система HomeMate для сторінок дашбордів

Єдина мова для SVG-макетів і для YAML-реалізації. Джерело — концепти
avtopoliv-concept-v1.svg і ohliad-concept-v2.svg (серпень 2026), затверджені
користувачем.

## Типографіка

Шрифт: Inter (fallback 'Segoe UI', sans-serif) — є у Figma, тому текст у SVG
лишається редагованим.

| Роль | Розмір / вага |
|---|---|
| Hero-статус | 26–32 / 700 |
| Заголовок секції | 16–17 / 700 |
| KPI-значення | 24–32 / 700 |
| Лейбл картки (UPPERCASE) | 13 / 400, колір text-secondary |
| Основний текст | 14–15 |
| Підписи, meta | 12–12.5, text-secondary або tertiary |

## Геометрія

- Полотно макета: 1440 px завширшки, відступ сторінки 32.
- Радіуси: картка 16, плитка 14, чип 16–17, кнопка 10–12.
- Проміжки між картками 24–32; сітка 4 колонок по 326 px (32+326×4+24×3+32).
- Кругова шкала (gauge у макеті): r=62, stroke 14, трек elevated, значення
  акцентним кольором, всередині — велике число + підпис.

## Готові SVG-фрагменти

Шапка файла:
```xml
<svg xmlns="http://www.w3.org/2000/svg" width="1440" height="H"
     viewBox="0 0 1440 H" font-family="Inter, 'Segoe UI', sans-serif">
  <rect width="1440" height="H" fill="#111318"/>
```

Картка: `<rect x="…" y="…" width="…" height="…" rx="16" fill="#1c1f26"/>`

Чип стану:
```xml
<rect x="X" y="Y" width="W" height="32" rx="16" fill="#12321c" stroke="#1f5a33"/>
<circle cx="X+20" cy="Y+16" r="5" fill="#43a047"/>
<text x="X+32" y="Y+21" font-size="13" font-weight="600" fill="#bff0cc">Текст</text>
```

Кругова шкала з часткою заповнення f (0..1), довжина кола 2πr ≈ 390 при r=62:
```xml
<circle cx="CX" cy="CY" r="62" fill="none" stroke="#2a2e37" stroke-width="14"/>
<circle cx="CX" cy="CY" r="62" fill="none" stroke="#00acc1" stroke-width="14"
        stroke-linecap="round" stroke-dasharray="{390*f} {390*(1-f)}"
        transform="rotate(-90 CX CY)"/>
```

Тумблер: трек `rect w=34 h=20 rx=10` (увімк. `#00acc1` / вимк. `#3a3f4a`),
повзунок `circle r=8` (`#04252b` / `#9aa0a6`) біля відповідного краю.

Таймлайн: вертикальна лінія `stroke #2a2e37 width 2`, точки `circle r=6` у
кольорі типу події, заголовок 14 + мета 12 tertiary.

## Відповідність макет → YAML

| У макеті | У Lovelace |
|---|---|
| Hero-статус + рядок рішення | markdown із Jinja |
| Чипи станів | tile rows:1 (або badges вью) |
| Кругова шкала | gauge (needle, severity) |
| KPI-картка з великим числом | statistic (change за day/month) або tile |
| Тумблер | tile на input_boolean/switch |
| Дні тижня чипами | glance columns:7, tap_action toggle |
| Акордеон | `<details><summary>` в одній markdown-картці |
| Таймлайн «Сьогодні» | logbook card по ключових сутностях |
| Стовпчики за 7 днів | statistics-graph chart_type bar, stat_types [change] |
| Превʼю камери | picture-entity з camera_image |
| Кнопка-дія | button з tap_action call-service / navigate |

Червону кнопку вбудованим button не зробити (без card-mod) — прийнятна
нейтральна зі значком mdi:stop-circle-outline.

## Чесність макета

Усі значення на макеті — реальні значення системи на момент малювання
(зібрані з hass.states або REST). Стани помилок теж показуються правдиво
(«гостьова: датчик офлайн»), бо порожні й аварійні стани — частина дизайну.
