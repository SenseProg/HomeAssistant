# Локальні патчі Smart Irrigation

Компонент ставиться не з репозиторію, а з релізу
`altmenorg/HAsmartirrigation` скриптом
`board-config/scripts/homemate-install-irrigation-components.sh`. Тому будь-яка
правка в `custom_components/smart_irrigation/` зникає при оновленні. Тут лежать
патчі, які треба накласти повторно.

Поточна версія компонента: **v2026.7.1**. Оригінали лежать на платі поруч із
файлами як `*.py.orig-v2026.7.1`.

## Як накласти

```bash
cd /userdata/hass/config/custom_components/smart_irrigation
patch -p0 --dry-run < calculation.patch   # спершу перевірка
patch -p0 < calculation.patch
patch -p0 < websockets.patch
```

Після накладання потрібен перезапуск Home Assistant: це Python, `reload` його не
підхоплює.

## calculation.patch — дубльований кінець пояснення

Блок «тривалість після часу випередження» додавався **двічі**, тому пояснення
кожної зони закінчувалося повтором речення і другою парою `</li></ol>`:

```
… отже остаточна тривалість становить 2898</li></ol>отже остаточна
тривалість становить 2898.</li></ol>
```

Патч прибирає перший із двох однакових блоків, лишаючи той, що з крапкою.

Дубль зникає з тексту не одразу: пояснення зберігається в зоні і переписується
на найближчому перерахунку, тобто о 19:55.

## websockets.patch — сирі HTML-теги в панелі Info

Пояснення зберігається як HTML. Панель **Zones** виводить його через
`unsafeHTML` і рендерить правильно, а панель **Info**
(`frontend/src/views/info/view-info.ts:428`) вставляє те саме значення як
звичайний текст, тому користувач бачив `<br/>`, `<ol>` і `<li>` прямо на екрані.

Правильно було б виправити фронтенд, але це TypeScript із збіркою rollup, якої
на платі немає. Тому патч перетворює HTML на читабельний текст на боці Python —
лише на шляху до Info, щоб не зламати панель Zones:

- `<li>` стає нумерацією `1) 2) 3)`;
- `<br/>`, `<ol>`, `</li>` та решта тегів прибираються;
- пробіли схлопуються.

Нумерація замість переносів рядків навмисна: у `.explanation-text` немає
`white-space`, тому `\n` усе одно перетворився б на пробіл.

Було:

```
…<br/><ol><li>Інтенсивність опадів визначається як 40.0 * 60 / 200.0 = 12.0.</li>
<li>Тривалість розраховується як 9.66 / 12.0 * 3600 = 2898.</li></ol>
```

Стало:

```
… 1) Інтенсивність опадів визначається як 40.0 * 60 / 200.0 = 12.0.
2) Тривалість розраховується як 9.66 / 12.0 * 3600 = 2898.
```

Зони розділяються рядком `———`.
